# כמה נשאר

אפליקציית עמוד יחיד (HTML בלבד) למעקב אחרי הוצאות חודשיות מול תקציב יומי של ₪300.

## הפעלה

פותחים את `index.html` בדפדפן. אין תלויות ואין שרת — כל הנתונים נשמרים ב-`localStorage` של הדפדפן.

## סנכרון אוטומטי מ-RiseUp

במקום להעלות CSV כל פעם, אפשר לחבר את האפליקציה ישירות ל-RiseUp Exposed API:

1. יוצרים טוקן אישי ב-<span dir="ltr">https://input.riseup.co.il/developer/tokens</span> עם הרשאת `budget:read`
   (הטוקן מוצג פעם אחת בלבד, ופג אחרי 30 יום כברירת מחדל).
2. באפליקציה: **הגדרות** ← מדביקים את הטוקן ← **שמור הגדרות**.
3. מכאן והלאה האפליקציה מושכת את הנתונים בכל פתיחה, וגם ידנית בכפתור **משוך נתונים מ-RiseUp**.

מאחורי הקלעים: `GET /api/external/transactions?cashflowMonth=YYYY-MM` עם
`Authorization: Bearer <PAT>`. מתוך התשובה נלקחות רק תנועות עם `sourceType = creditCard`
ו-`isIncome = false`. הסכומים ב-API תמיד חיוביים — הכיוון נקבע לפי `isIncome`.

חלוקה לימים: תנועה נספרת ל"הוצאות היום" רק אם `transactionDate` נופל בחודש הקלנדרי הנוכחי.
חיוב שהוקצה לתזרים החודש אבל נקנה קודם (דחייה / חיוב מאוחר) נספר בסך החודשי בלבד.

הטוקן נשמר ב-`localStorage` של הדפדפן ונשלח רק לכתובת שמוגדרת בהגדרות. אל תפרסם את הדף
עם טוקן שמור בתוכו.

### אם הסנכרון נחסם

ה-API נועד לשימוש משרת, ולא בהכרח מחזיר כותרות CORS לדפדפן. אם מופיע
"הקריאה נחסמה (CORS או אין רשת)" — פורסים את הפרוקסי הזעיר שב-[`proxy/`](./proxy),
ומפנים אליו את שדה הכתובת בהגדרות. הפרוקסי מחזיק את הטוקן בצד השרת, כך שהוא יוצא
מהדפדפן לגמרי.

## מה יש בפנים

- **סנכרון מ-RiseUp API** — כמתואר למעלה, כולל שגיאות מפורשות ל-401 (טוקן פג),
  403 (חסרה הרשאה), 429 (רייט-לימיט) וחסימת דפדפן.
- **טעינת קובץ CSV חודשי** — מייבא רק שורות של `סוג מקור = creditCard`, מסנן שורות מוחרגות מהתזרים, לוקח רק חיובים (סכום שלילי) בחודש הנוכחי לפי `תאריך התשלום`.
- **תקרה דינמית** — מחשבת כמה אפשר להוציא היום מתוך היתרה שנשארה לחודש, עד תקרה של ₪300.
- **הוספת הוצאות ידניות** — סכום + תיאור, נשמרות מקומית וניתנות למחיקה.
- **סיכום חודשי** — סה"כ הוצאה, ממוצע יומי, פער מקצב ₪300 ליום, ימים שנותרו.
- **תחקיר החודש** — ההוצאות הבודדות הגדולות ביותר, והוצאות חוזרות מקובצות לפי שם עסק.
- **התראת קצב ירידה** — כמה התקרה היומית יורדת ליום, ומתי בקצב הזה היא מגיעה ל-0.

## עמודות נדרשות ב-CSV

`סוג מקור`, `האם מוחרג מהתזרים?`, `סכום`, `תאריך התשלום` (בפורמט DD/MM/YYYY), `שם העסק`.
