# כמה נשאר

מעקב יומי אחרי הוצאות מול תקציב של ₪300 ליום, עם סנכרון אוטומטי מ-RiseUp.

## הפעלה

```bash
npm start        # ברירת מחדל: פורט 3000
```

`server.js` מגיש את `index.html` וגם משמש כמתווך ל-API של RiseUp. אין תלויות — Node 18+ בלבד.

בפריסה (Railway וכו') לא צריך הגדרות: הפלטפורמה מריצה `npm start` ומזריקה `PORT`.

## חיבור ל-RiseUp

1. יוצרים טוקן ב-[input.riseup.co.il/developer/tokens](https://input.riseup.co.il/developer/tokens)
   עם ההרשאה `budget:read`. הוא מוצג פעם אחת בלבד ופג אחרי 30 יום.
2. באפליקציה: ⚙ ← מדביקים ← **שמור וסנכרן**.

מכאן הנתונים נמשכים אוטומטית בכל פתיחה.

**אפשרות עדיפה:** להגדיר את הטוקן כמשתנה סביבה `RISEUP_PAT` על השרת. אז הוא לא נמצא
בדפדפן בכלל, והאפליקציה עובדת בלי להדביק כלום.

### למה צריך שרת ולא רק קובץ HTML

ה-API של RiseUp בנוי לשימוש משרת (זה מה ששרת ה-MCP הרשמי עושה) ולא שולח כותרות CORS.
קריאה ישירה מהדפדפן נחסמת ב-preflight, ואי אפשר לעקוף את זה מצד הלקוח. `server.js` מעביר
את הקריאה מאותו origin שמגיש את הדף, ואז מבחינת הדפדפן זו בכלל לא קריאה חוצת-מקורות.

```
דפדפן → GET /api/riseup/transactions?cashflowMonth=YYYY-MM
server.js → GET https://input.riseup.co.il/api/external/transactions?…
            Authorization: Bearer <PAT>
```

מותרים רק שני הנתיבים `transactions` ו-`budget`, כדי שהטוקן לא ידלוף לשום מקום אחר.

## משתני סביבה

| משתנה | חובה | ברירת מחדל | תיאור |
|---|---|---|---|
| `PORT` | לא | `3000` | פורט ההאזנה |
| `RISEUP_PAT` | לא | — | טוקן בצד השרת. אם מוגדר, מתעלמים מהטוקן שבדפדפן |
| `RISEUP_API_BASE` | לא | `https://input.riseup.co.il` | להחלפה בסביבת בדיקות |

## איך זה מחשב

- **תקרה דינמית** — מה שנשאר מהתקציב החודשי (₪300 × ימי החודש) מחולק בימים שנותרו,
  עד תקרה של ₪300. אחרי יום יקר התקרה של מחר יורדת.
- **מה נכנס** — רק תנועות `sourceType = creditCard` ו-`isIncome = false`. הסכומים ב-API
  תמיד חיוביים, אז הכיוון נקבע לפי `isIncome` ולא לפי הסימן.
- **הוצאות היום** — תנועה נספרת ליום רק אם `transactionDate` נופל בחודש הקלנדרי הנוכחי.
  חיוב שהוקצה לתזרים החודש אבל נקנה קודם (דחייה או חיוב מאוחר) נספר בסך החודשי בלבד.
- **תחזית לסוף החודש** — הממוצע היומי עד היום כפול ימי החודש, מול התקציב החודשי. עונה על
  "אם אמשיך להוציא ככה, עד סוף החודש אוציא יותר מדי או יישאר לי חיסכון?" ולא על
  "כמה חרגתי עד עכשיו".
- **גרף 7 ימים** — הוצאה יומית מול קו ה-₪300, לזיהוי דפוסים. עמודת היום כוללת גם את
  הרישום הזמני מהגלגלת; שאר הימים מרייזאפ בלבד, ולכן הימים האחרונים עלולים להיות חלקיים.
- **רישום זמני** — הגלגלת שבתחתית המסך היא הערכה של מה שהוצאת עכשיו, לפני שרייזאפ הספיק
  לקלוט את החיוב. היא מורידה רק את "נשאר להיום", ולא נוגעת בסך החודשי, בממוצע, בפער
  מהקצב או בתקרה — כל אלה מגיעים מרייזאפ בלבד. הרישום נמחק מעצמו בסוף היום, כי למחרת
  החיוב האמיתי כבר בפנים. עד אז הוא נשמר ב-`localStorage`.

## גיבוי: קובץ CSV

`סכום`, `תאריך התשלום` (DD/MM/YYYY), `שם העסק`.

Cloudflare Worker חלופי, למקרה שהדף מוגש כסטטי בלי `server.js`. עם השרת שבריפו הוא לא נדרש.
